# Contributing

- pnpm only; the lockfile is versioned.
- Every change passes `pnpm lint`, `pnpm test`, `pnpm build` and `pnpm e2e`.
- Each step of the plan has a design document in `docs/design/` written before the code.
- Symbols and library data are drawn from scratch under the same license as the code: no brand logos, no copied standards.
