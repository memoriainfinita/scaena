# Shortcuts

Also shown in the app with **?**.

| Key | Does |
|---|---|
| Tab / Shift+Tab | Next / previous plot element (focusing selects it). The first Tab stop on the page is “Skip to the main content” |
| Arrows | Move the selection one grid step (**Shift**: 10 mm); with nothing selected, pan |
| R / Shift+R | Rotate 15° each way |
| F / Shift+F | Flip horizontally / vertically |
| Ctrl+D | Duplicate |
| Ctrl+G / Ctrl+Shift+G | Group / ungroup |
| Del or Backspace | Delete the selection |
| Ctrl+A | Select all |
| Enter | Focus the element's label |
| Esc | Drop the selection and the tool, close a dialog |
| 0 | Fit the plot |
| + / − | Zoom in / out |
| Space + drag | Pan |
| Alt while dragging | No grid snap |
| Wheel | Zoom (**Shift**: horizontal pan) |
| Ctrl+Z / Ctrl+Shift+Z | Undo / redo |

Inside a text field the keys type: single-letter shortcuts do not act.
