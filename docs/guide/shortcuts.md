# Shortcuts

Also shown in the app with **?**.

| Key | Does |
|---|---|
| Tab / Shift+Tab | Next / previous plot element (focusing selects it). The first Tab stop on the page is “Skip to the main content” |
| Arrows | Move the selection one grid step (**Shift**: 10 mm); with nothing selected, pan |
| R / Shift+R | Rotate 15° each way |
| F / Shift+F | Flip horizontally / vertically |
| Ctrl+D | Duplicate |
| Ctrl+G / Ctrl+Shift+G | Group / ungroup |
| Del or Backspace | Delete the selection |
| Ctrl+A | Select all |
| Enter | Focus the element's label |
| Esc | Drop the selection and the tool, close a dialog |
| 0 | Fit the plot |
| + / − | Zoom in / out |
| Space + drag | Pan |
| Alt while dragging | No grid snap |
| Alt + arrows | Move the label of the selected element |
| Wheel | Zoom (**Shift**: horizontal pan) |
| Ctrl+Z / Ctrl+Shift+Z | Undo / redo |

Single-character shortcuts (**R**, **F**, **0**, **+**, **−**, **Space**, **?**) act only with focus on the plot, or on the page after a click on empty space. With focus on a button, a checkbox, a panel edge or any other control, that control keeps its keys: **Space** and **Enter** activate it, and the arrows work on it (on a panel edge they resize it). Inside a text field the keys type. The shortcuts with **Ctrl** work everywhere in the plot view; the menu has a button for the shortcut list.
