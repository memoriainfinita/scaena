# scaena guide

scaena prepares the technical rider of a live show: stage plot, input and output lists, light plot, the day's production and a PDF ready to send. Everything lives in your browser: no accounts, no server, nothing is sent anywhere. [Guía en español](es/README.md).

Screenshots are the Spanish interface (they are generated by `node scripts/screenshots.mjs`); switch the language in **Application settings**.

## Two ideas

- **Everything is a view of the same data.** A guitar you put on the plot shows up in the input list, the PDF and the reports; remove it and it goes everywhere.
- **Everything can be undone** (Ctrl+Z), including a drag or a restored revision.
