# Your data and privacy

- **Nothing leaves your computer.** scaena is a static page with no server of its own, no accounts, and it sends no show, list or PDF anywhere. PDFs are compiled in your browser.
- **Where your work is kept:** in the browser's own storage (IndexedDB), automatically. It reopens the last show.
- **Backups:** that copy is local; clearing the browser's data or changing computer loses it. To keep it for real, **Export → .scaena file** (a zip with the show and its images that opens in scaena anywhere).
- **Private mode:** some browsers keep nothing. scaena still works, without autosave or revisions; export the file before closing.
- **A file from a newer version** is refused with a message rather than half opened, and is never overwritten.
- **Contacts in the PDF:** each can hide its phone or email.
- **License:** free software under GPL-3.0; the licenses of what it includes are in `THIRD-PARTY-NOTICES.md`.
