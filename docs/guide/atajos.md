# Atajos

También se ven en la propia aplicación con la tecla **?**.

## En el plano

| Tecla | Hace |
|---|---|
| Tab / Mayús+Tab | Pasa de un elemento al siguiente; enfocar uno lo selecciona (el primer Tab de la página es «Saltar al contenido principal») |
| Flechas | Mueve la selección un paso de cuadrícula (con **Mayús**, 10 mm); sin selección, desplaza la vista |
| R / Mayús+R | Gira 15° a un lado o al otro |
| F / Mayús+F | Voltea en horizontal o en vertical |
| Ctrl+D | Duplica |
| Ctrl+G / Ctrl+Mayús+G | Agrupa / desagrupa |
| Supr o Retroceso | Borra la selección |
| Ctrl+A | Selecciona todo |
| Enter | Lleva el foco a la etiqueta del elemento |
| Esc | Suelta la selección y la herramienta |
| 0 | Encaja el plano |
| + / − | Acerca / aleja |
| Espacio + arrastrar | Mueve la vista |
| Alt al arrastrar | Sin ajuste a la cuadrícula |
| Rueda | Zoom; con **Mayús**, desplazamiento horizontal |

## En todas partes

| Tecla | Hace |
|---|---|
| Ctrl+Z / Ctrl+Mayús+Z | Deshacer / rehacer |
| ? | Mostrar los atajos |
| Esc | Cerrar el diálogo abierto |

Dentro de un campo de texto, las teclas escriben: los atajos de una letra no actúan.
