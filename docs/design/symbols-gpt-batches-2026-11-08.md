# Icon sheets for GPT, round 3 (2026-11-08)

Continues `symbols-gpt-batches-2026-11-07.md` (sheets 1 to 66). **Read that document first**: it holds the style blocks and the sheet template. For these sheets:

1. Paste **style block D** (objects) from that document, then the **sheet prompt** template, then the list of the sheet below.
2. For sheets with people (69) add the faceless clause: *Faces are completely blank, with no eyes, nose, mouth or expression, only the head outline and hair.*
3. One item per line with its size in cm; icons must not touch each other; ask for extras if GPT has room.
4. Item ids below already exist in the library, **except those marked new**, which I add together with the icon. Items that already exist have no icon yet: they draw the old top-view symbol until their sheet comes back.

Why these sheets: the catalogue (`icons-catalog.md`) shows where the library is thin. Counts today: PA 12 (13 more were added on 2026-11-08 without icon), monitors 7, desks 5, vocals 4, venue rooms 3, power 6, rigging 13. For the items marked **new** I add the item (size, power, layer, translated names and tags) together with the icon; for the 13 PA items that already exist I only add the icon. The library rule that two items never share an icon keeps holding.
