# scaena — modelo de datos y formato de archivo

Estado: lista de contenido confirmada por el usuario el 2026-10-29. Los campos son diseño propuesto y aprobado en la conversación; el detalle de tipos y esquemas está sin escribir.

## Reglas

- Todo elemento lleva un id estable y es serializable
- Lo derivable no se guarda; se guarda solo el ajuste manual encima
- Unidades internas: milímetros, kilogramos y vatios. Imperial solo al mostrar
- Posición de cada elemento en tres ejes (x, y, z); la interfaz usa dos. El 3D futuro lee el mismo modelo
- Deshacer de 200 pasos, con gestos agrupados
- Validadores como funciones puras sobre el modelo
- Plano, listas, plano de luces, informes y rider son vistas del mismo modelo

## Entidades

### Montaje
- Nombre
- Versión del formato
- Idioma
- Unidades (métrico, imperial)
- Papel (A4, Letter)
- Fecha
- Número de revisión y nota de cada revisión
- Región eléctrica: tensión y tipo de enchufe
- Mesa y show file

### Escenario
- Dimensiones y forma
- Líneas de referencia: centro, plaster, proscenio
- Escala
- Imagen de fondo
- Altura del escenario y datos del proscenio, para la sección lateral

### Elemento del plano
- Tipo de biblioteca (id y versión)
- Posición x, y, z
- Rotación y volteo
- Tamaño
- Capa
- Etiqueta
- Grupo
- Quién lo aporta: banda, sala o alquiler
- Notas
- Sobrescrituras de peso y potencia sobre los datos de la biblioteca

### Capa
- Nombre
- Materia: escenario, audio, luces, eléctrica, anotaciones, fondo o propia
- Visibilidad
- Bloqueo
- Atenuación
- Cada elemento pertenece a una sola capa
- Un solo plano del escenario con todas las capas (decisión de interfaz 1, 2026-10-29)

### Elemento propio del usuario
- Símbolo propio (imagen incluida en el archivo)

### Canal de entrada
- Número
- Nombre corto
- Micro o DI
- Pie
- Fantasma
- Insert
- Par estéreo
- Elemento de origen
- Derivado de los elementos del plano; ajustes manuales encima

### Salida y monitor
- Número
- Cuña o in-ear
- Mono o estéreo
- Frecuencia o AUX
- Stageboxes y patch

### Conexión de señal
- Origen y destino, para el flujo de señal de audio

### Rack
- Equipos del rack

### Luminaria
- Tipo (de la Open Fixture Library)
- Posición de montaje
- Número de unidad
- Canal
- Dimmer
- Circuito
- Universo y dirección
- Color
- Accesorios
- Punto de enfoque
- Notas

### Posición de montaje
- Tipo: barra, vara, truss, boom
- Nombre
- Geometría
- Altura
- Carga máxima

### Infraestructura eléctrica
- Circuitos
- Dimmers
- Fases
- Magnetotérmicos
- Las tomas de corriente son elementos del plano

### Nota de trabajo
- Estado
- Referencia a una posición o a una luminaria

### Contacto
- Datos de contacto
- Visibilidad por contacto y por campo, para ocultarlos al generar un enlace

### Horario
- Hitos del día y programación de montaje del evento

### Documentos (vistas del modelo)
- Rider: secciones y textos, incluidos hospitalidad y contrato
- Setlist
- Hoja de ruta del evento
- Programación de montaje
- Magic sheet, con disposición propia, independiente del plano
- Plan de varas
- Racks
- Flujo de señal
- Sección lateral

### Cajetín
- Datos de la producción
- Logo del usuario

### Configuración de informe
- Columnas
- Bloques
- Orientación
- Escala
- Preajuste de capas visibles
